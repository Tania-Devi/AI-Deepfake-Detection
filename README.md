# AI Deepfake Detection

## About the Project
AI Deepfake Detection is a Python-based application that uses a pretrained deep learning model to analyze images and videos and predict whether they are REAL or FAKE.

## Features
- Image deepfake detection
- Video deepfake detection
- Prediction confidence scores
- Simple web interface using Streamlit
- Supports common image and video uploads

## Technologies Used
- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- OpenCV
- NumPy
- Pillow

## How to Run the Project

### 1. Clone the Repository
```bash
git clone https://github.com/Tania-Devi/AI-Deepfake-Detection.git
cd AI-Deepfake-Detection
```

### 2. Create a Virtual Environment
```bash
python -m venv .venv
```

### 3. Activate the Environment on Windows
```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the Application
```bash
streamlit run app.py
```

## Disclaimer
This application provides model-based predictions. Results may be incorrect and should not be treated as definitive proof that an image or video is authentic or manipulated.
